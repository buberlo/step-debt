# Step Debt

> Every skipped walk becomes a tiny creditor marching in your shoes.

Your pedometer turns every missed step goal into a tiny creditor with a name, voice note, and demand for interest. Walk to pay down debt, use streaks to reduce interest, or negotiate payment plans for slow days. If debt is ignored, the creditors start planning a tiny rally in your shoes.

## Features
- Set a daily step salary and watch missed steps become named debt collectors.
- Pay debt with real steps, tracked via motion sensors or manual GPS walk.
- Negotiate payment plans with collectors and lock in lower interest streaks.
- Review a shoe ledger showing walked miles, forgiven debt, and collector moods.

## Stack
- React Native
- SQLite
- CoreMotion

## Getting started
```
npm install && npx pod install && npm run ios
```
